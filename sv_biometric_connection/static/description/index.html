Biometric Attendance Sync Manager (Queue Job Backend)

Seamlessly integrate Odoo HR Attendance with multiple ZKTeco, Ronald Jack, and Hikvision devices using optimized background queue workers.

Key Features & Highlights

Multi-Brand Compatibility

Supports a wide range of popular biometric devices using standard network protocols, including ZKTeco, Ronald Jack, and similar mainstream hardware.

Queue Job Batch Processing

Engineered for enterprise scale. Automatically breaks down enormous data pull requests into small, optimized batches using Queue Jobs to completely eliminate system timeout errors on multiple devices.

Smart Cron Automation

Runs silently in the background via Odoo Cron scheduled every 60 minutes. It targets and refreshes data logs from the previous day to maintain absolute data accuracy.

On-Demand Manual Pull Wizard

Includes a robust dynamic wizard allowing HR managers to explicitly pick any custom Start Date and End Date range to recalculate or pull missing logs manually.

Advanced Auditing & Logs

Never guess what went wrong. The module extends the native ir.logging model to provide crystal-clear metrics inside the Odoo UI. You can monitor the Total Records, Successful Records, and pinpoint Failed Records immediately filtered by hardware device.
